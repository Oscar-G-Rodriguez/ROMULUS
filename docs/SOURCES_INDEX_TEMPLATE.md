# Sources Index (Template)

Provide a unique SOURCE_ID for each reference. Do not paste full text from copyrighted sources. Use location markers such as chapter, section, or page where allowed.

Format:
- SOURCE_ID: <short-id>
  - Filename: <file>
  - Title: <title>
  - Author: <author>
  - Location markers: <chapter/section/page>
  - Notes: <why this source is relevant>

Example:
- SOURCE_ID: EXAMPLE_001
  - Filename: example_book.pdf
  - Title: Example Book
  - Author: Example Author
  - Location markers: Chapter 3, Section 2
  - Notes: Risk policy and audit trail guidance
