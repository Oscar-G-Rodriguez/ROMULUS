# ADR-002: Data Resolution Policy (Daily vs Weekly vs Non-Time Bars)

Status: Draft

## Context
ROMULUS must define the default bar resolution and conditions for alternative bar types. [SOURCE_PLACEHOLDER | LOCATION-TODO | bar resolution guidance]

## Decision
- Default research feed is daily OHLCV.
- Weekly resampling is allowed as a tournament configuration.
- Non-time bars are only allowed in a separate league with explicit justification and data support.

## Alternatives
- Only daily bars
- Only weekly bars
- Mixed bars without governance

## Consequences
- Requires provenance records to state resolution and resampling method.
